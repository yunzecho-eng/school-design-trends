# School Design Trends · 경기도 학교 설계 동향

경기도의 학교 설계 사례를 모아, 최근 3년의 변화와 시·군·구별 분포를 근거와 함께 살펴보는 웹 도구입니다.

**[웹 화면 바로 열기 →](https://yunzecho-eng.github.io/school-design-trends/)**

### 공식 데이터 연결 작업 · 2026-10-28

나이스·학교알리미·경기데이터드림·건축HUB·KOSIS의 로컬 수집기를 연결하는 작업입니다. **나이스는 인증키로 경기 응답 2,667행을 모두 받았고, 2,660행을 정규화했습니다.** 같은 학교 코드가 쓰인 2행과 코드가 없는 개교 예정 학교 5행은 원문을 보존해 식별 검토 대상으로 분리했습니다. 작품집 166개 사업 중 정확한 이름이 일치하는 후보는 8건이며, 학교·주소의 동일성 검토와 작품집 연결은 아직 완료되지 않았습니다.

| 연결 대상 | 현재 확인한 범위 | 다음 단계 |
|---|---|---|
| 나이스 | 인증 조회 2,667행 · 정규화 2,660행 · 검토 보류 7행 | 8개 이름 일치 후보와 약칭·가칭·변경 학교명의 주소 대조 |
| 학교알리미 | 705개 인증 요청 · 응답 12,740행 · 정규화 12,736행 · 분류 검토 보류 4행 | 학교별 항목과 나이스·작품집의 동일성 대조 |
| 경기데이터드림 | 사무소 표본 5행 확인 | 키 발급 후 전체 조회·동일 사무소 검토 |
| 건축HUB | 인증키 발급·활용신청 승인 후 학교 2곳의 2필지 조회 · 건물 후보 3행 | 학교·동의 동일성 대조, 사용승인일 누락 보완, 조회 필지 확대 |
| KOSIS | 공식 대량자료 다운로드로 31개 시·군·6–17세·2023~2025년 12월의 1,116행 수집 | 비교 화면 연결·경계 변화 검토. API 인증키는 미발급 |

건축HUB는 군포초 조회 필지에서 A·B·C동 후보 3행을 받았고 가남초 조회 필지는 0행이었습니다. 세 행 모두 사용승인일이 없어 **연령을 계산할 수 있는 건물은 아직 0행**입니다. 자료 생성일을 준공일로 대신하지 않으며, 한 필지의 빈 응답을 학교 건물 전체가 없다는 뜻으로 해석하지 않습니다. KOSIS의 1,116행은 `31개 시·군 × 12개 연령 × 3개 12월 시점`의 관측 셀이며 인구 합계가 아닙니다. 수집 방법은 공식 파일 다운로드이고 인증키 API 호출과 구분합니다.

학교알리미의 현재 시험 명령은 1개 시군구를 요청하며 225개 표본 레코드를 확인했습니다. 초기의 시도 단위 시험 300개 레코드와 요청 범위가 다르고, 어느 쪽도 고유 학교 수가 아닙니다. 이 항목은 **작업 브랜치의 구현·조회 기록**이며, 아래의 2026-10-19 공개 배포 기록과 구분합니다.

`npm run data:connect -- status`로 상태를 확인하고 기관별로 수집할 수 있습니다. 키와 수집 원본·연결 후보는 로컬 비공개 폴더에 보관하며, 화면에는 각 기관의 연결 상태를 표시합니다. 기존 166건과 학교·사무소를 자동 합치거나 시험 응답을 전체 통계로 사용하지 않습니다. **[키 발급부터 연결까지](docs/API_SETUP.md)**

KOSIS 공식 파일 방식은 다음과 같이 명시적으로 선택합니다. API 실패 시 자동으로 이 방식으로 바꾸지 않습니다.

```powershell
npm run data:connect -- kosis --bulk --config data/config/kosis-population.example.json
```

이번 작업의 자동 테스트는 **264개 통과·실패 0**이며, 공개 대상 검사 파일 121개에서 설정된 인증키 3개의 값 노출은 없었습니다. 로컬 화면에서 기관별 수집 범위와 건물 연령 계산 불가 안내, 기존 작품집 166건 유지를 확인했습니다. 이 결과는 작업 브랜치의 검증 기록이며 병합·push·배포 완료를 뜻하지 않습니다. [상세 검증 기록](docs/API_CONNECTION_VERIFICATION.md)

처음 열면 **경기도교육청 설계공모 작품집 2023·2024·2025의 당선작 166건**을 볼 수 있습니다. 지역·학교급·수록연도로 사례를 찾고, 사업 규모와 설계 개념, 출처와 검수 메모를 확인합니다. 연도별 키워드를 가상 학교의 3D 공간 개념도와 연결해 살펴볼 수도 있습니다.

자료는 **수작업·AI 보조 입력과 직접 작성한 요약이며, 사람의 원문 검수가 필요합니다.** 경기 작품집에 실린 당선작 표본으로 학교 외 교육시설·유치원·관사 등도 포함합니다. 경기도 전체 사업을 빠짐없이 집계한 통계나 준공 실적이 아닙니다. 기능 확인용 가상 자료도 선택할 수 있습니다.

위 주소는 다른 PC에서도 열립니다. `127.0.0.1` 주소는 해당 PC에서 미리보기 서버가 실행 중일 때만 사용할 수 있습니다. 저장소의 `index.html`은 웹페이지 소스이므로 파일을 더블클릭하기보다 온라인 주소 또는 아래 로컬 서버를 이용하세요.

## 먼저 이렇게 사용하세요

1. **‘살펴볼 자료’를 고릅니다.** 기본은 경기 작품집 166건입니다. ‘가상 예시’를 선택하면 이미지·날짜·건물 연령 기능을 가상 자료로 확인할 수 있습니다. 페이지 아래의 ‘Snapshot JSON 불러오기’는 규격 v0.1/v0.2의 실제·가상 JSON을 브라우저 안에서 읽습니다.
2. **조건을 고릅니다.** 작품집 자료는 ‘수록연도’를 선택하고 검색어·경기도 시·군·구·학교급·설계 주제로 좁힙니다. 작품집의 연도는 실제 당선일이나 준공일이 아닙니다. 날짜 기준으로 바꾸면 날짜가 확인된 사업만 조회합니다.
3. **지도에서 시·군을 누릅니다.** 마우스를 올리거나 Tab으로 이동하면 지역명과 현재 조건의 사례 수가 나타납니다. 클릭·Enter·Space로 선택하고, 일반구가 있는 도시는 구 단위로 더 좁힙니다. ‘시 전체’ 또는 ‘경기도 전체’로 돌아갈 수 있습니다. 그래프·사례·내보내기는 같은 조건을 쓰며, 모바일은 지도 다음에 결과가 이어집니다. 지역 이름 버튼으로도 선택할 수 있습니다.
4. **간결한 카드에서 상세와 원문을 엽니다.** 자세한 개요·면적·설계자·검수 메모는 상세에 모았습니다. 페이지를 대조한 9건은 공식 작품집의 해당 도판을 뷰어로 보고, 나머지는 작품집 원문 링크를 엽니다. 원문 열람을 이미지 사용 허가로 표시하지 않습니다. [확인한 사례와 페이지](docs/PROJECT_IMAGES.md)
5. **‘연도별 분석’에서 키워드와 공간을 연결합니다.** ‘키워드를 공간으로 이해하기’를 펼치면 가상 학교의 전체 외관이 먼저 보입니다. ‘내부 투과’ 슬라이더로 앞쪽 공간을 살펴보고 ‘전체 외관’으로 복귀합니다. 회전·확대·투과 설정은 키워드를 바꿔도 유지되며 SVG로 저장할 수 있습니다. [공간 모델 안내](docs/SPATIAL_MODEL.md)
6. **조회 결과를 저장합니다.** CSV/Markdown은 공통 검색·지역·학교급·주제·수록연도 조건의 사업 목록과 자료 한계를 담습니다. 연도별 패널 안의 ‘살펴볼 연도’만 바꾸는 것은 패널 선택이며, 전체 다운로드의 조건을 바꾸려면 위쪽 공통 ‘수록연도’를 선택하세요. 공간 모델에서 강조하는 키워드는 사업 집계나 CSV 행 수를 바꾸지 않습니다.

3D 개념도는 직접 작성한 가상 형상입니다. 실제 학교 재현·실측 도면·BIM이 아니며, 연결된 사례는 **키워드 분류의 근거**입니다. 저장한 SVG에는 모델 출처·이용 조건·가정과 연결 근거가 함께 들어갑니다. 코드·모델의 이용 조건과 외부 원문·이미지의 권리는 구분해야 하며, 원문이 공개되어 있다는 이유만으로 이미지를 재배포하지 않습니다.

지도는 **2026-10-01 기준 경기도 31개 시·군과 24개 일반구**를 표시합니다. 166개 사업의 시·군은 모두 확인되지만 일반구가 있는 도시의 **15건은 구 미확인**으로 남습니다. 과거 화성시 주소 등을 현재 구에 추정 배정하지 않으며, 시 전체 건수에는 포함합니다. 경계는 화면용으로 단순화한 자료입니다. [지도 사용 안내](docs/REGION_MAP.md) · [출처·이용 조건](docs/MAP_SOURCE.md)

## 자료를 읽을 때 확인할 점

| 자료와 집계 기준 | 결과 | 해석 |
|---|---:|---|
| 경기 작품집 · 전체 수록연도 | 166건 | 2023년 42건 · 2024년 69건 · 2025년 55건 |
| 경기 작품집 · 실제 당선일 기준 | 0건 조회, 166건 날짜 미확인 | 당선일이 없어서 제외된 결과이며 수록연도로 날짜를 만들지 않음 |
| 가상 예시 · 당선일 기준 | 11건 조회, 1건 날짜 미확인 | 총 12건의 기능 검증용 가상 사업 |
| 가상 예시 · 사업 준공일 기준 | 6건 조회, 6건 날짜 미확인 | 2024년 1건 · 2025년 2건 · 2026년 3건 |

실제 자료의 기준일은 **2026-10-17**이며, 다음 항목을 검토해야 합니다.

- **확인·검수 메모:** 현재 84개 사업에 중복 제거 후 208개 메모가 있습니다. 수치 오류뿐 아니라 출처 쪽수·판독·검수 상태가 포함된 숫자입니다. 화면은 현재 조회 조건에서 다시 계산합니다.
- **2024년 분류 누락:** 69건의 개념·설계자 정보는 보완됐지만 주제 태그와 사무소 식별자 연결은 아직 없습니다. 주제 정보 없음은 0%가 아니며, 미분류가 있는 연도 사이의 키워드 증감은 보류합니다. 설계자 이름이 있다고 사무소 참여 집계에 자동으로 더하지 않습니다.
- **검수 상태:** 2023·2025년의 주제 근거는 `draft_ai` 초안입니다. 2024년 심사평 중 사업 귀속이 불확실한 2건은 비워 두었고, 2025년 쪽수는 목차 번호와 본문 번호의 대조가 필요합니다.
- **출처·이미지:** 2023년 원문 URL을 공식 목록과 대조해 보완했습니다. 2023·2024·2025년 각 3건, 총 9건의 대표 도판 페이지를 확인해 공식 뷰어로 연결합니다. 나머지 쪽수는 추정하지 않습니다. 개별 이미지 파일의 복사·재배포 허가는 아직 확인하지 않았습니다.
- **사무소 API:** 경기도 공식 API의 키 없는 표본 5건을 조회했고, API가 알린 전체 건수는 3,421건입니다. 표본에서 작품집 사무소와 정확히 일치한 항목은 없지만, 76개 사무소의 전체 검색 결과가 없다는 뜻은 아닙니다. 전체 조회용 키와 동일성 검수가 필요합니다. 사업자번호·홈페이지·영업 상태는 이 API 제공 항목이 아닙니다.
- **학교·건물 정보:** 나이스에서 정규화한 학교 2,660행은 별도 비공개 수집 목록에 보관합니다. 작품집 166건과는 이름 일치 후보 8건을 검토하는 단계입니다. 학교 식별 문제 7행과 학교알리미 분류 보류 4행도 남아 있습니다. 건축물대장의 확인된 2필지 조회에서는 건물 후보 3행을 받았지만 모두 사용승인일이 없어 실제 건물 연령을 계산하지 않습니다. 작품집에 연결된 학교·건물 수로 자동 반영하거나 개교일·자료 생성일로 준공일을 추정하지 않습니다.

인증키는 공개 화면에 입력하지 않습니다. 사무소 API 전체 조회와 건축물대장 수집은 로컬 수집 도구에서 실행하고, 검토한 공개용 결과만 화면에 연결합니다. 건축물대장은 인증키 외에도 학교와 대조한 지번이 필요합니다. **[공식 API 발급·연결 안내](docs/OFFICIAL_DATA.md)**

날짜로 조회할 때 전년 비교는 두 연도의 전체 날짜 범위가 포함된 경우에만 제공합니다. 작품집 비교는 수록된 당선작 수의 차이이며 실제 연간 발주량의 증감이 아닙니다. 전망 영역은 **근거·가정·대안·검토자·검토일을 채울 작성·검토 대기 틀**이며 자동 예측 결과를 제공하지 않습니다.

## 로컬에서 실행하기

Node.js 22.12 이상에서 별도 패키지 설치 없이 실행합니다. 검증 환경은 Node.js 24.14.0입니다. A1의 JSON 모듈 import attributes를 고려한 버전 기준입니다([Node.js 문서](https://nodejs.org/api/esm.html#import-attributes)).

```bash
npm start
# http://127.0.0.1:4173/
npm test
```

서버 실행 후 [로컬 미리보기](http://127.0.0.1:4173/)를 열고 위 사용 순서대로 살펴봅니다. 기본 자료와 날짜 기준은 경기 작품집·수록연도입니다. 실제·가상 Snapshot JSON을 최대 5MB까지 브라우저 안에서 가져올 수 있으며 외부로 전송하지 않습니다. 가상 예시의 기본 기준은 당선일이고, 당선일·공모일·기사 게시일·사업 준공일 조회도 유지합니다.

화면은 `src/ui/data-provider.js`에서 Daniel의 A1/A2를 호출합니다. 조회와 내보내기는 같은 검색·필터를 사용하고, 여러 시도에 걸친 사업·결측·경고를 표시합니다. 잘못된 입력은 이전 자료와 조회 결과를 유지한 채 안내합니다. 이전 `demo-provider.js`는 초기 UI의 비교 테스트용으로 남겨 두었습니다. [연결 안내](docs/UI_HANDOFF.md), [이번 연결 검증](docs/UI_CONNECTION_VERIFICATION.md), [첫 병합 검토](docs/INTEGRATION_REVIEW.md)를 참고하세요.

```bash
node scripts/check-snapshot.js public/demo.snapshot.json
# 가상 자료의 기본 당선일 조회: 사업 11건 · 출처 13건 · 학교 11곳
```

`npm test`는 UI·자료 처리·두 모듈 간 대조 테스트를 모두 실행합니다. 실제 작품집 검증에는 연도별 42/69/55건, 날짜 결측 166건, 2024년 분류 누락, 선택 결과와 내보내기의 일치가 포함됩니다. 위 검사 스크립트의 기본 날짜 조회와 작품집 수록연도 조회를 혼동하지 마세요.

## 협업 순서

1. [기획·업무 분담](docs/PLAN.md)과 [데이터 규격](docs/DATA_CONTRACT.md)을 합의합니다.
2. 담당자에게 이슈를 할당하고 이름·날짜가 들어간 작업 브랜치를 만듭니다.
3. 같은 자료와 필터로 화면·집계·내보내기를 검증하고 입력·기대 결과·한계를 기록합니다.
4. PR에서 변경을 검토한 뒤 main에 병합합니다. 에이전트 검증과 팀원의 직접 승인 리뷰는 구분합니다.
5. main 병합 뒤 GitHub Pages 반영을 확인하고 관련 이슈와 README 상태를 갱신합니다.

수업용 첫 판은 **서버와 도구 내부 AI 호출 없이 작동**하도록 설계합니다. AI는 개발을 돕는 도구로 사용합니다. 월별 자동 수집은 출처·필드·접근 조건이 확인된 뒤 별도 단계로 구현합니다. 현재 예약 작업은 설정하지 않았습니다.
