# KOSIS 인구 연결 설정의 확인 근거

작성자·최종 수정자: yunze · 확인일: 2026-10-28

`data/config/kosis-population.example.json`은 **경기도 31개 시·군의 6–17세 주민등록인구를 2023·2024·2025년 12월 기준으로 요청**하는 설정이다. 학교 설계 사례의 수록연도와 나란히 볼 배경 자료이며 재학생 수, 통학 수요, 미래 예측이 아니다.

`verified: true`는 아래 공식 코드표와 내려받기 자료로 **선택 코드·명칭·자료의 존재를 대조했다**는 뜻이다. API 인증키 발급·인증 성공·화면 연결 완료나 세부 행정경계의 불변을 의미하지 않는다. 인증키는 설정에 포함하지 않고 무시되는 로컬 `.env`의 `KOSIS_API_KEY`를 사용한다.

## 공식 출처와 재확인 방법

- [KOSIS 공식 개발 가이드](https://kosis.kr/openapi/devGuide/devGuide_0201List.do): `orgId`, `tblId`, `objL1`–`objL8`, `itmId`, `prdSe`, `startPrdDe`, `endPrdDe` 및 응답 필드의 의미.
- [행정구역(시군구)별/1세별 주민등록인구 대량통계목록](https://kosis.kr/statisticsList/mass/mass_list.jsp?list_id=A_7&org_id=101&process=statHtml&tbl_id=DT_1B04006&vw_cd=MT_ZTITLE): 통계표 `101 / DT_1B04006`의 메타자료 내려받기와 연도별 월자료 ZIP.
- 해당 목록의 상단 메타자료 내려받기로 `101_DT_1B04006_meta.csv`를 받는다. **분류/항목 정보**에서 첫 번째 분류 `A`가 지역, 두 번째 분류 `YRE`가 연령이며 `T2`가 `총인구수`, 단위는 `명`임을 확인한다.
- 2023·2024·2025 행의 **시점표측, 항목표두 다운로드**로 각각 `101_DT_1B04006_M_YYYY.zip`을 받는다. ZIP 안 CSV는 CP949이며 열은 지역코드·지역명·연령코드·연령명·시점·총인구수·남자인구수·여자인구수 순서다. 코드 앞 작은따옴표는 CSV의 문자열 보존 표시이므로 API 코드에 넣지 않는다.
- 메타자료의 생성일은 **2026-10-06 09:10:16**이었다. 메타자료의 월별 수록기간은 `200801`–`202609`, 연자료는 `2008`–`2025`로 표시됐다.

위 내려받기는 로그인·인증키 없이 실제로 응답했다. 이 경로는 API와 별개인 공식 대량자료 배포 방식이며 API 인증 성공으로 표시하지 않는다.

## 확인한 요청 범위

| 설정 | 확인한 값 |
|---|---|
| 기관 / 통계표 | `101` / `DT_1B04006` |
| 지역 축 | 첫째 분류 `A` → `objL1` / 응답 `C1` |
| 연령 축 | 둘째 분류 `YRE` → `objL2` / 응답 `C2` |
| 인구 항목 | `T2` · 총인구수 · 명 |
| 주기 | `M` · 월 |
| 시점 | `202312`, `202412`, `202512` |
| 지역 | 경기도 31개 시·군 전체 행만 선택 |
| 연령 | 6–17세, 총 12개 단일 연령 |

| 연령 | 코드 | 연령 | 코드 |
|---:|---|---:|---|
| 6 | `0502` | 12 | `0703` |
| 7 | `0503` | 13 | `0704` |
| 8 | `0504` | 14 | `0705` |
| 9 | `0505` | 15 | `1001` |
| 10 | `0701` | 16 | `1002` |
| 11 | `0702` | 17 | `1003` |

31개 시·군 코드와 이름은 메타 CSV에서 직접 대조했다. 현재 프로젝트의 `rules/gyeonggi.json`의 시·군 31개 코드·명칭과 모두 일치했지만, 다른 통계표나 미래 자료에 이 일치를 자동 확대하지 않는다. 실제 API 응답에서도 코드·명칭·연령명·단위·조회 월을 다시 검사한다.

각 연도 12월 CSV에서 **31개 시·군 × 12개 연령 = 372행**을 확인했다. 3개 연도 합계 1,116행이며 `(지역코드, 연령코드, 시점)` 중복과 선택 항목의 빈 수치는 없었다. 이 숫자는 학교 수·인구 수가 아니라 선택된 통계 관측 행 수다.

## 지역·시점 해석

- 경기도 전체 `41`과 시·군 전체를 함께 선택하지 않는다. 시 전체와 소속 일반구, 출장소를 함께 합산하지 않는다.
- 메타 주석에는 부천시 원미·소사·오정구의 **2024-01-01 신설**, 화성시 만세·효행·병점·동탄구의 **2026-02-01 신설**이 표시되어 있다. 본 설정은 이 일반구들을 제외하고 부천시 `41190`, 화성시 `41590`의 시 전체 행을 사용한다. 폐지된 여주군도 선택하지 않는다.
- 같은 시·군 코드가 계속 존재한다는 사실만으로 세부 경계가 전혀 변하지 않았다고 단정하지 않는다. 자동 전년 증감·수요 전망을 만들기 전 해당 비교지역의 경계 변경 여부와 통계 정의를 추가 확인한다.
- 메타 주석상 등록구분의 전체는 거주자·거주불명자·재외국민을 포함한다. 주민등록 신고 기준이므로 실제 거주·통학 인구와 같지 않을 수 있다.
- 12월 값은 해당 월의 연령별 인구다. 학생 수·취학률·해당 연도 입학생 수로 바꾸지 않는다. 세 해는 비교 시점을 맞췄지만 작품집 수록연도와 학교의 실제 건축·입학 시점이 같다는 뜻도 아니다.

## 확인한 파일 해시

해시는 다운로드 당시 원본 바이트의 SHA-256이다. 원본 ZIP·CSV를 공개 저장소에 복사하지 않았다. 공식 자료가 수정되면 해시가 달라질 수 있으므로 재조회 결과의 갱신일과 함께 기록한다.

| 파일 | SHA-256 |
|---|---|
| `101_DT_1B04006_meta.csv` | `db0b24b94c24dd2382aed386a1044358e77da8ca6e3081fda034ddd13f037a5e` |
| `101_DT_1B04006_M_2023.csv` | `0393c3058e89b46b381b837cb150d842df81e028a2a23abd2631b6beb5914156` |
| `101_DT_1B04006_M_2024.csv` | `c6f1a9029c2cf57c08d6ef9e9663babd9a3d4123eebec9fbb980435b7afe6f41` |
| `101_DT_1B04006_M_2025.csv` | `504aeeaac62b78d658367923a8df179c608eface143451f3da89b20daa72c437` |

`fetchKosisPopulation`는 인증키를 받은 뒤 이 설정으로 월별 3회 요청한다. 조회 결과가 372행보다 적거나 중복되면 누락을 0명으로 채우지 않고 실패시켜 이전 결과를 보존할 수 있게 한다. 사용자 키를 이용한 API 조회 결과는 별도로 검증해야 한다.

## 인증키 없는 공식 대량자료 수집

`src/integrations/kosis-bulk.js`의 `fetchKosisBulkPopulation({config})`는 위 공식 공개 배포 경로를 사용한다. OpenAPI 요청을 우회하거나 계정·키를 대신 사용하는 기능이 아니다. 사용자가 명시적으로 선택한 대량자료 수집 방식이며, 결과에 `method: official_bulk_download`, `authenticated_api: false`를 남긴다.

1. 공식 대량통계목록에서 실제 게시된 연도별 파일번호를 읽는다. 현재 목록에 없는 파일 경로나 번호를 추정하지 않는다.
2. 메타자료의 통계표·분류축·지역·연령·총인구 항목과 단위를 설정과 대조한다.
3. 선택 연도의 ZIP을 순서대로 읽고 단일 CSV 이름·압축 크기·해제 크기·CRC를 검증한다. 원문을 디스크에 풀거나 저장하지 않는다.
4. CP949 CSV를 읽어 명시한 시·군·연령·월만 선택한다. 정수 값의 `8820.0000` 같은 표기를 보존하며 총인구와 남녀 합계도 대조한다.
5. 기존 인구 정규화 함수를 적용하여 월별 예상 행 수·중복·코드·명칭·단위를 다시 확인한다. 모든 연도가 통과한 뒤에만 전체 결과를 반환한다. 실패 시 일부 행을 반환하거나 파일을 쓰지 않으므로 호출자가 이전 성공 결과를 유지할 수 있다.

조회 결과에는 공식 다운로드 URL, 조회 시각, 원본 ZIP과 CSV의 SHA-256, 메타자료 파일 생성 시각이 포함된다. 파일 생성일을 관측치 수정일로 대신 사용하지 않으며 `source_updated_at`은 확인되지 않으면 `null`이다. 한 실행의 다운로드는 최대 6개 연도, ZIP당 8 MiB, CSV당 64 MiB로 제한한다. 별도 설치 패키지 없이 Node 내장 기능을 사용한다.

구현한 모듈로 공식 자료를 실제 조회하여 **31개 시·군 × 12개 연령 × 3개 시점 = 1,116행**, 선택 범위의 결측 0행을 확인했다. ZIP의 CRC와 위에 기록한 3개 CSV의 SHA-256이 모두 일치했다. 결과의 `scope: complete`는 이 선택 범위의 수집 완료이며, OpenAPI 인증이나 학교·작품집 사례와의 연결 완료를 뜻하지 않는다.
