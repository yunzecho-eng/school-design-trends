건축HUB·KOSIS는 키와 추가 설정이 없어 실제 인증 요청을 실행하지 않았다. 전체 인증 조회, 실제 학교·사무소 동일성 검토, 기존 Snapshot 반영은 완료되지 않았다.

## 자동·화면 검증

- `npm test`: 230개 통과, 실패 0. 기존 기능과 새 API 응답·공시 제외·결측·페이지 중복·수집 범위 검사 포함.
- CLI 통합 테스트는 임시 폴더와 네트워크 차단 환경에서 실행. 키 누락 종료코드 2, 요청 실패 종료코드 1, 기존 전체 수집값 보존, 표본의 덮어쓰기 차단, 최신 실패 반영 확인.
- 공개 상태는 허용 목록으로 생성. 인증값·원본·연결 후보·원시 오류·사용자 지정 URL은 출력에 포함하지 않음.
- 로컬 HTTP에서 `/.env`, `/data/private/api-connections.json`은 404, 공개 현황과 발급 안내는 200 확인.
- 브라우저에서 연결 현황 펼치기, 세 기관의 시험 수신 건수, 건물·인구의 인증/추가 조건 필요 표시 확인. 기존 작품집은 166건 유지.
- HTML 작성자 메타데이터 `yunze` 확인.

이 기록은 개발 테스트이며 공동 작업자의 직접 승인 리뷰나 실제 데이터 전수 검수 완료를 뜻하지 않는다. 인증키 등록 후 실제 전체 응답에 대해 추가 검증한다.
