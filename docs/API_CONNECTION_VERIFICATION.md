# API 연결 검증 기록

작성·수정: yunze · 2026-10-28

작업 브랜치: `yunze/2026-10-28-official-api-connections`

이 문서는 작업 브랜치의 로컬 구현·요청 결과를 기록한다. 이번 변경의 GitHub 병합·push·배포 완료를 의미하지 않는다. 기존 2026-10-19 배포와 193개 테스트 기록은 README의 해당 날짜 항목에 유지한다.

구현 통합은 [이슈 #43](https://github.com/yunzecho-eng/school-design-trends/issues/43), 자료의 식별·중복·결측 검토는 [#44](https://github.com/yunzecho-eng/school-design-trends/issues/44)로 나눈다. 수집 성공만으로 학교·사무소 동일성과 건물 날짜가 확정되지 않으므로 기존 [공식 자료 연결 #40](https://github.com/yunzecho-eng/school-design-trends/issues/40)은 열어 둔다.

## 실제 인증 조회 · 나이스

`npm run data:connect -- neis`로 경기도교육청 `J10`의 학교기본정보를 인증 조회했다.

| 확인 항목 | 결과 |
|---|---:|
| API 보고 전체 응답 행 수 | 2,667 |
| 실제 수신 | 1,000 + 1,000 + 667 = 2,667행 |
| 정규화한 학교 행 | 2,660 |
| 식별 검토 보류 | 7행: 같은 코드의 서로 다른 2행 + 코드 없는 5행 |
| 정규화 ID 고유 수 | 2,660 |
| 격리 행과 정규화 목록의 ID 중첩 | 0 |
| 작품집 사업별 매칭 기록 | 166 |
| 정확한 이름 일치 후보 | 8개 사업 · 8개 학교 |
| 이름 기준 미연결 | 158개 사업 |
| 검수 완료 표시·끊어진 후보 참조 | 각각 0 |

`raw_count = retrieved_count + quarantined_count`가 성립한다. `scope: complete`는 원시 응답 수집 완료, `normalization_complete: false`는 식별 문제 7행이 남아 있다는 뜻이다. 학교 코드가 같은 서로 다른 과정·학교를 임의 병합하지 않으며, 코드 없는 개교 예정 학교에 ID를 만들지 않는다. 격리 원문과 사유는 비공개 `school_quarantine`에 보존한다.

8건은 공백을 정규화한 이름 일치 후보일 뿐 주소·사업 동일성이 검수된 학교가 아니다. 158건은 학교 부재를 뜻하지 않는다. 약칭, 학교명 뒤 시설·사업명이 붙은 제목, 가칭·개교 예정, 통합학교, 학교 외 교육시설을 별도로 대조해야 한다. 현재 작품집 Snapshot의 학교·건물 연결을 자동으로 변경하지 않았다. 학교 설립·개교일을 건물 준공일이나 연령 필드로 복사한 행은 없다.

## 실제 인증 조회 · 학교알리미

인증키 발급·로컬 저장 후 **705개 요청의 실제 응답 12,740행**을 받았다. 처음 실행은 학생 공시항목의 학교급 예외로 중단되어 이전 결과를 보존했다. 재검증 과정에서 이미 받은 공식 응답을 비공개 캐시에 보관해 재사용하고 나머지 요청을 마쳤으며, 같은 응답을 일반 CLI 경로로 다시 검증해 저장했다. 키와 인증 URL은 캐시에 포함하지 않았다.

| 확인 항목 | 결과 |
|---|---:|
| 요청 조합 / 완료 | 705 / 705 |
| 원시 응답 행 | 12,740 |
| 정규화 행 | 12,736 |
| 기본정보(0) | 2,612 |
| 교실(17)·지원시설(18)·시설개방(20)·학생(62) | 각 2,531 |
| 분류 검토 보류 | 4행 |

일반 중학교(`03`) 요청의 학생 항목에 방송통신중학교(`25`) 4행이 함께 반환됐다. 이를 일반 중학교로 바꾸지 않고 `requested_school_kind_mismatch`로 원문·요청 맥락을 비공개 `schoolinfo_quarantine`에 보존했다. `12,740 = 12,736 + 4`이며, 원시 응답 수집 완료와 정규화 완료를 구분한다. 공시항목별 레코드 합을 고유 학교 수로 해석하지 않는다.

705개 요청 조합의 누락·중복과 `(항목, 학교코드)` 중복은 없었다. 공시 제외 수치 860개와 결측 수치 25,296개는 각각 제외·결측으로 유지했으며 0으로 대체하지 않았다. 기본정보 2,612개에는 폐교 표시 42개·휴교 표시 3개(둘 다 표시된 1개 포함)가 있어 현재 운영 학교 수가 아니다.

2025년 공시의 학교집합 2,531개는 네 항목에서 같았다. 현재 기본정보와 과거 공시의 코드 합집합은 2,613개다. 과거 공시에만 있는 서신중학교 1개와 현재 기본정보에만 있는 82개가 있으며, 차이를 폐교·신설·개명으로 임의 해석하지 않는다. 나이스·작품집과의 동일성 검토도 남아 있다.

2026년 신규 키의 `sggCode` 지정 안내에 맞춰 [공식 코드표](https://www.schoolinfo.go.kr/download/sido_sggCode.xlsx)와 조회 화면의 경기 47개 말단 시군구를 사용한다. 초·중·고 3개 학교급과 기본정보·학생·교실·지원시설·시설개방 5개 항목을 조합한 **705개 요청**이다. 부모 시와 일반구·과거 코드를 섞지 않는다. 2025년 공시자료를 조회할 때도 현재 조회 코드표 기준이며 과거 행정경계를 복원한 결과가 아니다.

[공식 제공목록](https://www.schoolinfo.go.kr/ng/go/pnnggo_a01_l0.do)의 요청제한횟수는 ‘제한없음’으로 표시된다. 수집기는 요청을 직렬로 처리하고 기본 100ms 간격을 둔다. 일부 조합이 실패하면 전체 실행을 성공으로 저장하지 않는다. 명시적인 자료 없음 응답은 `no_data`로 보존한다.

## 실제 표본 요청 이력

| 시점·범위 | 수신 | 해석 |
|---|---:|---|
| 초기 나이스 무인증 시험 | 5행 | 이후 위의 인증 전체 조회로 갱신 |
| 초기 학교알리미 시도 단위 시험 | 300레코드·15요청 | 당시 시군구를 지정하지 않은 표본. 고유 학교 수 아님 |
| 현재 학교알리미 시군구 지정 시험 | 225레코드·15요청 | 수원시 장안구 `41111` × 초·중·고 × 5항목. 현재 `--sample`의 범위 |
| 초기 경기데이터드림 사무소 시험 | 5행 | 이후 아래의 인증 전체 조회로 갱신 |

학교알리미 300→225는 요청 지역 범위 변경이며 학교 수나 학생 수의 감소가 아니다. 표본 조회로 이미 저장된 전체 조회 결과를 덮어쓰지 않는다.

## 실제 인증 조회 · 경기데이터드림 사무소

회원가입과 인증키 발급·로컬 저장 후 `npm run data:connect -- firms`를 실행했다. [건축사 사무소 현황](https://www.data.go.kr/data/15057636/openapi.do)의 전체 응답을 받았으며 계정 식별정보·키·인증 URL은 공개 기록에 포함하지 않는다.

| 확인 항목 | 결과 |
|---|---:|
| 응답 시·군 | 31개 |
| API 보고 전체 / 수신 원시 행 | 3,421 / 3,421 |
| 정규화 행 | 3,419 |
| 중복 검토 보류 | 같은 원문 2행 |
| 작품집 사무소 매칭 기록 | 76곳 |
| 단일 이름 후보 | 17곳 |
| 복수 이름 후보 | 2곳: 각각 2개·3개 후보 |
| 정규화 미완료로 검색 확정 보류 | 57곳 (`not_searched`) |
| 검수 완료 표시 | 0곳 |
| 후보 참조 / 참조된 정규화 레코드 | 22 / 21 |
| 끊어진 후보 참조 | 0 |

첫 페이지의 773·774번째 원문이 동일해 둘 다 `duplicate_raw_record`로 비공개 `firm_quarantine`에 보존했다. 한 행을 임의로 남기거나 합치지 않았다. `3,421 = 3,419 + 2`이며 `scope: complete`와 `scope_basis: raw_response_rows_collected`는 원시 응답의 수집 범위를 가리킨다. `normalization_complete: false`이므로 후보가 없는 57곳을 `not_found`로 확정하지 않는다.

정규화한 3,419행의 `data_as_of`는 모두 미제공이다. 조회일·API 요청 성공일을 자료의 갱신일로 대신하지 않는다. 이름 후보는 주소·사무소 동일성 검토 전이고 경기 밖 소재 업체가 빠질 수 있다. 사업자등록번호·홈페이지·영업 상태를 이 응답에서 추론하지 않는다. 원시 응답과 후보는 비공개로 보관하며 공개 상태에는 허용한 수집·정규화·보류 건수만 반영한다.

## 실제 인증 조회 · 건축HUB

[건축HUB 건축물대장정보 서비스](https://www.data.go.kr/data/15134735/openapi.do)의 활용신청 승인 후 인증키를 무시되는 로컬 `.env`에 저장했다. 학교 주소와 지번을 대조한 비공개 필지 설정으로 다음 명령을 실행했다.

```powershell
npm run data:connect -- buildings --parcels data/private/school-parcels.json
```

| 요청 범위 | 수신 결과 | 검토 상태 |
|---|---:|---|
| 군포초등학교의 확인된 1필지 | A·B·C동 3행 | 학교·동 연결 후보 |
| 가남초등학교의 확인된 1필지 | 0행 | 해당 필지 응답에 자료 없음 |
| 합계 | 2필지 조회 완료 · 후보 3행 | 연령 계산 가능 0행 |

조회 완료는 지정한 2필지의 요청 범위에 한정한다. 경기도 모든 학교나 두 학교의 모든 필지를 수집한 결과가 아니다. 가남초의 빈 응답도 학교 건물이 없다는 뜻으로 해석하지 않는다. 군포초 후보 3행은 사용승인일이 모두 미제공(`null`)이었다. 원문 생성일 `20220909`를 준공일로 사용하지 않았으며 건물 연령 확보 완료로 표시하지 않는다. 건물 식별·학교 소속·동·현존 여부를 검토하기 전까지 `candidate_only`로 보존하고 기존 작품집의 학교·건물 연결을 자동 변경하지 않는다.

## 실제 공식 파일 수집 · KOSIS

[KOSIS 공식 자료 대조 기록](KOSIS_SOURCE.md)에 따라 통계표 `101 / DT_1B04006`의 경기 31개 시·군, 6–17세 12개 연령, 총인구수 `T2`, `202312`·`202412`·`202512`를 선택했다. 다음 명령으로 공식 대량자료를 내려받아 선택 범위의 1,116행을 비공개 수집 목록에 저장했다.

```powershell
npm run data:connect -- kosis --bulk --config data/config/kosis-population.example.json
```

| 확인 항목 | 결과 |
|---|---:|
| 요청 시·군 / 연령 / 시점 | 31 / 12 / 3 |
| 선택한 관측 셀 | 1,116행 |
| 지역·연령·시점 고유 조합 | 1,116개 |
| 시점별 행 수 | 각 372행 |
| 선택 범위의 결측 | 0행 |
| 공식 메타자료·내려받기 파일 해시 | 저장한 SHA-256 근거와 모두 일치 |

수집 결과에는 `method: official_bulk_download`, `authenticated_api: false`와 출처·파일 해시를 보존한다. 이 방식은 `--bulk`로 명시적으로 선택하며 인증 API 실패 시 자동 전환하지 않는다. KOSIS 인증키는 아직 발급하지 않았고 인증 API 응답도 검증 전이다. 공식 파일 수집 성공을 인증 API 연결 성공으로 표시하지 않는다. 1,116행은 인구 합계가 아닌 관측 셀이며, 연속 36개월이 아니라 각 연도의 12월 세 시점이다.

설정의 `verified: true`는 선택 코드·자료 존재 확인을 뜻한다. 세부 행정경계 불변, 재학생 수, 통학 수요, 미래 예측을 확인했다는 의미는 아니다.

## 자동·화면 검증

- NEIS의 빈 코드·동일 코드 충돌·동일 행 중복·반복 페이지·총건수 변경을 검사한다. 동일 페이지를 행·필드 순서만 바꿔 재응답해도 실패 처리한다.
- 최종 `npm test`: 경기 사무소 전체 조회·중복 격리 변경까지 포함해 **270개 통과, 실패 0** (`test-final.log`). 2026-10-28 앞 단계의 264개 통과 기록과 구분한다. `git diff --check`도 통과했으며 CRLF 변환 안내만 있었다.
- CLI 통합 테스트는 임시 폴더와 네트워크 차단 환경에서 실행한다. 키 누락 종료코드 2, 요청 실패 종료코드 1, 이전 성공·격리 자료 보존, 표본의 전체 결과 덮어쓰기 차단, 최신 실패 반영을 확인했다.
- 공개 상태는 허용 목록으로 생성한다. 인증값·원문·격리 사유·연결 후보·원시 오류·사용자 지정 URL은 포함하지 않는다. NEIS의 응답·정규화·격리 건수 합을 검사하고 서로 맞는 수치만 표시한다.
- 로컬 HTTP에서 `/.env`, `/data/private/api-connections.json`은 404, 공개 연결 상태 JSON은 200이었다. 최종 로컬 브라우저에서 나이스 2,667/2,660/7행, 학교알리미 12,740/12,736/4행 및 47/47개 구역, 경기 사무소 3,421/3,419/2행과 검수 전 후보 상태, 건축HUB 후보 3행·사용승인일 확인 0행·미확인 3행과 연령 계산 불가 안내, KOSIS 공식 CSV 1,116행을 확인했다. 5개 출처의 연결 상태를 확인했으며 기존 작품집 166건도 유지됐다.
- 추적 파일과 Git 제외 대상이 아닌 파일 총 **121개**를 현재 설정된 **4개 인증키**의 실제 값과 대조했다. 일치한 파일은 없었다(`credential_match_files: []`). 앞 단계의 3개 키 검사를 갱신한 결과다. 키와 응답 캐시·격리 원문·건물 후보·인구 레코드는 무시되는 로컬 경로에만 보관하며 공개 상태 JSON에는 원본 레코드를 넣지 않는다.
- HTML 작성자 메타데이터와 이 문서의 작성자·최종 수정자는 `yunze`다.

이 기록은 개발 검증이며 공동 작업자의 직접 승인 리뷰나 실제 데이터 전수 검수 완료를 뜻하지 않는다.

현재 저장소에는 별도 CI 워크플로가 없다. 위 테스트는 로컬 실행 결과다. GitHub Pages 설정은 `main` 브랜치의 루트(`/`)를 배포하며, 확인한 `built` 상태는 이전 커밋의 배포 결과다. 이번 작업의 병합·배포 성공 근거로 사용하지 않는다.
